# Contributing (Draft)

**Status:** PROPOSED

## Documentation Changes
- Follow `docs/00-governance/documentation-standards.md` (metadata, IDs, traceability, evidence labels).
- Do not invent facts, dates, approvals, or external system states.
- Update `docs/00-governance/open-questions.md` and `docs/00-governance/decision-log.md` when applicable.
- For material changes to approved/baselined docs, follow `docs/00-governance/revision-and-approval-policy.md`.

## Pull Requests (when repository workflow is active)
- Use clear scope and link impacted requirement/decision IDs.
- Include validation notes for structural/traceability checks where relevant.
