# ADR-007: Framework Frontend Web Dashboard (React 18 + Vite + Tailwind CSS + shadcn/ui)

## 1. Konteks & Masalah (Context)
DomiBox memerlukan antarmuka Web Dashboard yang responsif, modern, dan berkinerja tinggi untuk mengelola domain, membuat temporary mailbox dalam satu klik, menampilkan pesan masuk terpadu, dan menyalin kode OTP secara instan.

Infrastruktur hosting frontend:
- Frontend harus disajikan sebagai aset statis murni (*Static Site Generation / SPA*) oleh Caddy Reverse Proxy tanpa memerlukan server runtime Node.js sisi server (SSR) yang memakan RAM VPS.
- Memerlukan komponen UI bertaraf industri dengan aksesibilitas tinggi dan dukungan dark mode bawaan.

---

## 2. Faktor Pendorong Keputusan (Decision Drivers)
1. **Nol Konsumsi RAM Server:** Kompilasi menjadi file HTML/JS/CSS statis murni yang di-*serve* oleh reverse proxy web server (`NFR-001`).
2. **Kecepatan Build & DX:** Vite memberikan waktu kompilasi instan via ES Modules.
3. **Komponen UI Modular (shadcn/ui + Tailwind CSS):** Kode komponen berada langsung di dalam repositori (*copy-paste component philosophy*), tidak ada vendor lock-in NPM runtime bundle besar, mendukung keyboard shortcut dan isolasi iframe sandboxing (`FR-007`, `NFR-007`).

---

## 3. Pilihan yang Dipertimbangkan (Options Considered)

| Parameter Evaluasi | Opsi 1: React 18 + Vite + shadcn/ui (Dipilih) | Opsi 2: Next.js (SSR / Fullstack) | Opsi 3: SvelteKit SPA |
| --- | --- | --- | --- |
| **Beban RAM di VPS** | **Nol RAM** (Statis murni di Caddy) | Tinggi (>150–200 MB untuk proses Node.js SSR) | **Nol RAM** (Statis murni) |
| **Ekosistem Komponen** | Sangat Kaya (Radix UI / shadcn/ui / Lucide Icons) | Sangat Kaya | Sedang |
| **Waktu Muat Awal** | Cepat (<1.5 detik, di-cache Caddy/Cloudflare) | Sangat Cepat | Sangat Cepat |
| **Kompatibilitas Tim** | Sangat Luas (Standar industri global) | Luas | Terbatas |

---

## 4. Keputusan yang Diambil (Decision Outcome)
Memilih **Opsi 1: React 18 + Vite + Tailwind CSS + shadcn/ui (Single Page Application)**.

Frontend dikompilasi saat proses CI/CD menjadi bundel statis di direktori `dist/`, lalu dimuat oleh Caddy dengan kompresi Brotli/Gzip dan header cache browser yang agresif.

---

## 5. Konsekuensi Positif & Negatif (Consequences)
### Konsekuensi Positif:
- Tidak ada beban memori tambahan di VPS untuk rendering halaman web.
- Waktu respons perpindahan halaman instan di sisi browser pengguna (*client-side routing* via TanStack Router atau React Router).
- Desain antarmuka bersih dengan palet warna modern, responsif untuk layar ponsel maupun desktop (`NFR-007`).

### Konsekuensi Negatif & Mitigasi:
- *SEO tidak optimal:* Karena SPA murni.
  - *Mitigasi:* DomiBox adalah aplikasi dashboard privat/internal single-owner yang tidak memerlukan publikasi indeks mesin pencari (*SEO is non-requirement*).
