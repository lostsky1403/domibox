# ADR-006: Runtime dan Framework Backend (Node.js LTS / Fastify / TypeScript)

## 1. Konteks & Masalah (Context)
DomiBox Core API membutuhkan runtime dan framework backend untuk melayani antarmuka REST API, memproses penguraian email MIME masuk secara asynchronous, menjalankan background scheduler TTL, dan mengelola webhook Telegram Bot.

Kebutuhan teknis:
- Waktu booting cepat dan overhead memori rendah (<150 MB RAM).
- Validasi skema request/response bawaan berkinerja tinggi.
- Keamanan tipe data penuh (*end-to-end type safety*) menggunakan TypeScript.

---

## 2. Faktor Pendorong Keputusan (Decision Drivers)
1. **Performa Throughput & Jejak Memori Rendah:** Menangani konkurensi I/O tinggi dengan efisiensi memori terdepan di ekosistem Node.js (`NFR-001`, `NFR-002`).
2. **Validasi Skema Bawaan (Ajv / JSON Schema):** Validasi otomatis payload request selaras dengan spesifikasi OpenAPI 3.1 tanpa library eksternal yang membebani CPU.
3. **Ekosistem TypeScript Matang:** Integrasi mulus dengan Kysely/Prisma, Mailparser, DOMPurify, dan pustaka Bot Telegram (`grammY`).

---

## 3. Pilihan yang Dipertimbangkan (Options Considered)

| Parameter Evaluasi | Opsi 1: Node.js LTS + Fastify + TypeScript (Dipilih) | Opsi 2: Node.js LTS + Express.js | Opsi 3: Go (Golang) + Gin/Echo |
| --- | --- | --- | --- |
| **Konsumsi Memori** | Rendah (~110–130 MB) | Sedang (~130–160 MB) | Sangat Rendah (~30–50 MB) |
| **Throughput HTTP** | Sangat Tinggi (~45.000 req/sec) | Rendah–Sedang (~15.000 req/sec) | Sangat Tinggi (~60.000 req/sec) |
| **Validasi Skema** | Bawaan (Ajv compilation, JSON Schema/TypeBox) | Manual (Perlu Zod/Joi middleware terpisah) | Struct tags manual |
| **Kecepatan Pengembangan** | Sangat Cepat (Ekosistem NPM kaya untuk MIME & sanitasi) | Cepat | Sedang (Pustaka parsing MIME kompleks di Go lebih terbatas) |

---

## 4. Keputusan yang Diambil (Decision Outcome)
Memilih **Opsi 1: Node.js 24 LTS + Fastify v4/v5 + TypeScript**.

Fastify dipilih karena arsitektur berbasis plugin yang modular, dukungan native JSON Schema validation, serializer teroptimasi, serta performa throughput hingga 2–3x lebih cepat dibanding Express dengan footprint memori yang ramping.

---

## 5. Konsekuensi Positif & Negatif (Consequences)
### Konsekuensi Positif:
- Kode skema API di Fastify dapat langsung disinkronkan dengan kontrak OpenAPI 3.1 (`docs/04-technical/api/openapi.yaml`).
- Penanganan asynchronous I/O non-blocking sangat ideal untuk pemrosesan paralel banyak email masuk.

### Konsekuensi Negatif & Mitigasi:
- *Single-thread CPU bound saat parsing file raksasa:*
  - *Mitigasi:* Pembatasan ukuran maksimum email masuk (max 15 MB) dan pemrosesan lampiran besar secara streaming buffer terisolasi.
