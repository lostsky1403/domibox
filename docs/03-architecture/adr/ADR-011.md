## 1. Konteks & Masalah (Context)
DomiBox harus berjalan pada satu VPS Tencent Cloud dengan sumber daya terbatas (3.6 GiB RAM, 60 GiB SSD) dan sistem operasi Ubuntu 24.04.4 LTS. Arsitektur layanan mencakup:
- Layanan aplikasi (Web, API, Bot) yang bersifat stateless/container-friendly.
- Layanan MTA/SMTP (Stalwart) yang membutuhkan binding langsung ke port-privileged 25 dan akses file system khusus untuk TLS/queue.
- Database (PostgreSQL) yang membutuhkan persistensi data kuat.

Terdapat pertanyaan operasional: apakah seluruh stack harus di-containerize, atau apakah ada model hybrid yang lebih stabil?

---

## 2. Faktor Pendorong Keputusan (Decision Drivers)
1. **Stabilitas Port 25 & Manajemen TLS:** Mail server membutuhkan keandalan tinggi dalam menangani koneksi SMTP inbound dan pembaruan sertifikat TLS.
2. **Efisiensi Sumber Daya:** Beban memori Docker daemon + lapisan container untuk komponen yang jarang berubah harus dipertimbangkan pada VPS 3.6 GiB.
3. **Kemudahan Operasi & Pembaruan:** Aplikasi web/API/bot sering diperbarui (iterasi cepat MVP); mail server dan database lebih stabil.

---

## 3. Pilihan yang Dipertimbangkan (Options Considered)

| Parameter Evaluasi | Opsi 1: Hybrid (Stalwart Native + Docker Compose App/DB) (Dipilih) | Opsi 2: Full Docker Compose (Semua Layanan) | Opsi 3: Full Native (Semua Layanan Systemd) |
| --- | --- | --- | --- |
| **Keandalan Port 25** | **Tinggi** (Native process bind langsung) | Baik (butuh port mapping & network mode host/bridge tuning) | **Tinggi** |
| **Kemudahan Deploy App** | **Tinggi** (docker compose up untuk app) | **Tinggi** (satu stack) | Rendah (manual dependency management) |
| **Isolasi Database** | **Baik** (Docker volume terisolasi) | **Baik** | Sedang (shared host FS) |
| **Overhead Memori** | Rendah–Sedang | Sedang (lebih banyak container layer) | **Rendah** |

---

## 4. Keputusan yang Diambil (Decision Outcome)
Memilih **Opsi 1: Strategi Deployment Hybrid**.

- **Native (Systemd):** Stalwart Mail Server dijalankan sebagai layanan native `systemd` untuk mengelola port 25/587/IMAP, TLS, dan antrian surat secara langsung dan stabil.
- **Docker Compose:** PostgreSQL, Fastify API, grammY Bot, dan SvelteKit Web (atau static serve via reverse proxy) dijalankan dalam `docker-compose.yml` tunggal untuk kemudahan orkestrasi, isolasi jaringan internal, dan pembaruan aplikasi yang atomik.
- **Reverse Proxy:** Caddy atau Nginx (native atau container) menangani TLS/HTTPS untuk web dan API, serta meneruskan trafik ke container aplikasi.

Topologi jaringan:
- Docker network internal untuk `app ↔ db ↔ bot`.
- API berkomunikasi dengan Stalwart native melalui host network (`host.docker.internal` atau IP host) pada port management API Stalwart.

---

## 5. Konsekuensi Positif & Negatif (Consequences)
### Konsekuensi Positif:
- Mail server mendapatkan stabilitas dan performa native terbaik untuk port 25.
- Siklus hidup pengembangan aplikasi (Web/API/Bot) tetap cepat dengan Docker Compose.
- Database tetap terisolasi dan mudah di-backup via Docker volume.

### Konsekuensi Negatif & Mitigasi:
- *Dua model manajemen layanan (systemd + docker):* Tim operasi harus memahami keduanya.
  - *Mitigasi:* Dokumentasi runbook operasi (`docs/07-operations/runbook-operations.md`) mencakup prosedur start/stop/restart untuk kedua model. Skrip deployment wrapper menyederhanakan perintah umum.
